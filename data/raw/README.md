# Raw Text Dataset Directory

This directory stores raw, unmodified UTF-8 text corpora used as benchmark inputs for the rANS source coding and Polar channel coding research project.

## Accepted Corpora Types
- Standard text compression benchmarks (e.g., excerpts from Project Gutenberg, Canterbury Corpus, or Silesia Corpus).
- Multi-domain UTF-8 plain text files (e.g., natural language English, source code, structured JSON/XML).

## Usage Guidelines
- Raw files placed here must be UTF-8 encoded text files.
- Raw files should remain immutable; preprocessed artifacts belong in `data/processed/`.
- Large benchmark files should be documented with source attribution and checksums in experiments.
